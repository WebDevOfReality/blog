# AGENTS.md — Content Directory Directives

> **Binding directive for AI agents working in `src/content/`.**
> Extends the root `AGENTS.md`. Where this file is stricter, this file wins.

## The iron rules

1. **Every post declares its AI provenance.** Frontmatter must include
   `aiAssisted`, and when true, `aiModel` + `aiScope`. `src/lib/posts.ts`
   validates this at build time; invalid or unsigned AI content **fails the
   build**. Do not remove or weaken validation.
2. **`aiScope: 'ai-generated'` is forbidden.** Fully AI-authored original posts
   are never allowed. The only fully generated content permitted is
   `ai-generated-from-human-source` — AI adapting Anthony's own material
   (e.g., vlog transcript → write-up).
3. **No AI-generated art.** Never create or commit images, logos, thumbnails,
   icons, or illustrations generated by AI — including as "placeholders."
   Need art? Leave a `TODO(art:)` note and stop. The site logo is commissioned
   from a human graphic designer.
4. **Posts are written by Anthony.** Do not author original opinion posts with
   AI. When asked to draft, ground every claim in material Anthony provided
   (transcripts, notes, brand docs) and mark the post `ai-assisted` honestly.
5. **Voice:** short paragraphs, scannable, code examples early and often,
   personal war stories ("here's what broke at 2 AM…"), no gatekeeping, assume
   intelligence not knowledge, self-deprecating humor where it fits.

## Frontmatter schema

```yaml
---
title: string            # required
description: string      # required, used for SEO + cards
date: YYYY-MM-DD         # required
tags: [string]           # optional, 3-5 tags
author: Anthony          # required
draft: boolean           # optional, hides post from listing
featured: boolean        # optional, surfaces on homepage
videoId: string          # optional, YouTube id for embedded video
aiAssisted: boolean      # required for any AI involvement
aiModel: string          # required when aiAssisted, e.g. "GLM (glm-5.3-flash) by Z.ai"
aiScope: ai-assisted | ai-generated-from-human-source  # required when aiAssisted
---
```

## Adding a post

Posts are auto-discovered: any `.mdx` file in this directory is picked up at
build time (slug = filename). No registration, no sibling meta files.

Two ways to publish:

1. **CMS (recommended for writing):** `/admin/` — Sveltia CMS commits
   `src/content/blog/<slug>.mdx` directly to `main`; Netlify deploys on
   push. The editor form enforces the frontmatter schema below.
2. **By hand:** create `src/content/blog/<slug>.mdx` with complete
   frontmatter, then `npm run build` — the disclosure validator must pass.

## Honesty standard

If Anthony provided an outline and AI expanded it into prose, that is
`ai-assisted` — label it. If a transcript was reworked into a post, that is
`ai-generated-from-human-source` — label it. When in doubt, disclose; over-
disclosure is free, under-disclosure is a violation of the directive.
