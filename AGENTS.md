# AGENTS.md — WebDev of Reality Blog

> **This file is a binding directive, not documentation.** It governs how any AI
> agent, coding assistant, or automation tool may operate in this repository.
> Violations of the AI Ethics Directive below are build-breaking.

## What this project is

The WebDev of Reality blog (`webdevofreality.dev`) — the public home of Anthony
Renteria's build-in-public journey building **Spider-Verse OS**: a distributed
operating system for his homelab (Talos Linux, K3s, Nebula mesh, AI "Spider"
agents). Stack: **TanStack Start** (Vite + React 19 + SSR via Nitro) + MDX +
Tailwind, deployed to **Netlify**.

## AI Ethics Directive (NON-NEGOTIABLE)

This project is grounded in **ethical AI**. Every rule below is enforced by the
content pipeline in `src/lib/posts.ts` (`validateAiDisclosure`). Content that
violates these rules fails the build — by design.

### 1. Transparency: label and sign all AI content

- Any content in `src/content/` that was produced with AI assistance **must**
  declare it in frontmatter:
  - `aiAssisted: true`
  - `aiModel: "<model name and version, e.g. GLM (glm-5.3-flash) by Z.ai>"`
  - `aiScope: <one of the scopes below>`
- The blog renders this as a visible **AI disclosure badge** on the post and on
  every blog card. Unsigned AI content must never ship.
- AI coding agents working on this repo must leave a similar paper trail in
  commit messages (e.g. `ai-assisted: GLM by Z.ai`) when a change was
  substantially generated by AI.

### 2. No AI-generated art — ever

- **Never** generate, upsert, or commit AI-generated images, illustrations,
  logos, icons, thumbnails, favicons, or any other visual asset.
- The site logo and all visual identity work is commissioned from human
  graphic designers, or made crudely by hand by Anthony. Both are acceptable;
  AI art is not.
- If a task requires new artwork: leave a `TODO(art:)` note describing the need
  and stop. Do not fill the gap with AI output, including placeholder art from
  image-generation tools.

### 3. Human authorship is the default for posts

- Blog posts are written by Anthony. Do not author original blog posts, essays,
  or opinion content with AI unless Anthony explicitly asks in a given session.
- The only fully AI-generated text permitted is **transformation of human
  source material** (e.g., vlog transcript → blog write-up). The ideas,
  opinions, and voice must originate from Anthony. AI is the adapter, not the
  author.
- When drafting or editing content at Anthony's request, preserve his voice:
  short paragraphs, code early and often, personal war stories, no-BS tone,
  self-deprecating humor when appropriate.

### 4. Allowed `aiScope` values (frontmatter)

| Value | Meaning | Allowed? |
|---|---|---|
| `human-written` | No AI involvement. | ✅ (omit AI fields entirely) |
| `ai-assisted` | Human-authored; AI helped with editing, snippets, research. | ✅ |
| `ai-generated-from-human-source` | AI transformed Anthony's own material (transcript → post). | ✅ |
| `ai-generated` | Fully AI-authored original content. | ❌ **Rejected at build time.** |

## Engineering conventions

- **MDX pipeline:** `remark-gfm`, `remark-frontmatter`, `remark-mdx-frontmatter`
  are configured in `vite.config.ts`. Never remove them — GFM tables and
  frontmatter parsing are load-bearing (learned the hard way on the docs site).
- **New posts:** add the `.mdx` file in `src/content/blog/`, then register the
  component and metadata in `src/lib/content.ts` (posts are statically
  imported; frontmatter lives in a sibling `.meta.ts` file — see
  `welcome.meta.ts`). Include complete, honest AI disclosure fields.
- **Content pipeline is the enforcement layer:** `validateAiDisclosure` throws
  on missing/forbidden AI metadata. Do not weaken, bypass, or remove it. If a
  legitimate need conflicts with it, stop and ask Anthony.
- **Styling:** Tailwind 4 CSS-first config in `src/styles/app.css` (brand
  palette: spider purple `#6B2D91`, electric red `#E63946`, void black
  `#0A0A0F`, neon blue `#00D4FF`, glitch pink `#FF6B9D`). Dark mode is the
  default; fonts are Space Grotesk (headings), Inter (body), JetBrains Mono
  (code) via Google Fonts.
- **Routing:** TanStack Start file-based routes in `src/routes/`. Post pages are
  `/blog/$slug`. Keep static prerendering enabled in `vite.config.ts`.
- **TypeScript:** strict mode. Run `npm run typecheck` before committing.
- **SEO:** per-route `head()` metadata is required for new routes. Every
  blog post route must emit title/description/OG tags from frontmatter.
- **No analytics without consent-first tooling:** analytics is self-hosted
  Umami (heim k3s). Never add third-party trackers or ad scripts.
- **Comments in code:** only when asked. Keep the code lean.

## Definition of done for content work

- [ ] Frontmatter complete (title, description, date, tags, author)
- [ ] AI disclosure fields present and accurate (or absent for human-written)
- [ ] `npm run build` passes (including disclosure validation)
- [ ] No AI-generated imagery introduced
- [ ] Voice matches the brand: friendly expert, no-BS edge
